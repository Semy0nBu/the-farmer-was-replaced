# Sources and compatibility

The scripts are based on the farms developed during a base-game playthrough, with earlier versions retained where they make sense for a smaller set of unlocks. The guides describe their requirements and practical limits rather than presenting one script as best at every stage.

The main mechanics reference is the English documentation included with the installed game: crop pages, Senses, Speed, expansion, Mega Farm, Polyculture, timing, and the language reference. The public repository does not redistribute that documentation, the game files, or a save.

- [The Farmer Was Replaced on Steam](https://store.steampowered.com/app/2060160/The_Farmer_Was_Replaced/)
- [Official updates](https://steamcommunity.com/app/2060160/announcements/)
- [4 December 2025 update](https://steamcommunity.com/games/2060160/announcements/detail/529864539779367365), including retained immature cactus sizes and changes to sunflower harvesting

Check your installed documentation after game updates. Older internet examples may use earlier command signatures or assume mechanics that have changed.
